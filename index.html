Frequently asked questions

What this prototype can—and cannot—do today.

Is LumaLive already a live video chat website?

No. It is a static landing-page prototype. The buttons show a preview notice; no real people are connected.

Can I host it for free?

Yes. Because this version uses static HTML, CSS, JavaScript, and an SVG icon, you can publish it on a static hosting service such as GitHub Pages or Netlify. The external sample portrait requires an internet connection.

Will video calls and paid filters work after upload?

No. Hosting publishes the landing page only. Real calls, user matching, accounts, moderation, and payments need separate services and secure backend integration.

Can the design be changed later?

Yes. The colors, text, profile card, button labels, sections, and logo can all be customized in index.html and styles can be adjusted in its CSS.
