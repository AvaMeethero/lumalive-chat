LumaLive Landing Page — Free Hosting Package
Suggested GitHub repository name: lumalive-chat

Included:
- index.html: responsive landing page
- favicon.svg: custom icon
- README.txt: deployment instructions

GitHub Pages (free):
1. Sign in at https://github.com/
2. Create a PUBLIC repository named lumalive-chat.
3. Upload index.html and favicon.svg to the repository root.
4. Open Settings -> Pages.
5. Select Deploy from a branch, branch main, folder /(root), then Save.
6. Wait for deployment. Copy the URL shown in Settings -> Pages.

The project URL usually looks like:
https://YOUR-USERNAME.github.io/lumalive-chat/
Replace YOUR-USERNAME with your actual GitHub username. This is only an example.

Alternative free static hosting:
https://app.netlify.com/drop

Important: this is a static landing page only. Real user matching, video/audio calls, accounts, chat storage, and payments are not connected. These require backend and real-time services, moderation, privacy terms, age/consent controls, and reporting/blocking. The sample portrait loads from Unsplash and requires internet access.
